# Карта переноса в Telegram Mini App

Текстовый бот остаётся рабочей точкой входа, каналом уведомлений и запасным
сценарием. Общая бизнес-логика находится в `TennisService`; Mini App обращается
к тонкому HTTP API и не повторяет правила подсчёта.

| Возможность в боте | Экран Mini App | Действие/API | Ошибка и запасной путь |
| --- | --- | --- | --- |
| `/start`, `/menu` | `Матчи` | `GET /api/profile`, `GET /api/opponents` | Текстовый бот открывает главное меню; Mini App показывает повтор загрузки |
| Список соперников | `Матчи` | `GET /api/opponents` | Пустой экран с действием «Добавить соперника» |
| Карточка соперника и ввод счёта | Экран матча | `GET /api/opponents/{id}/stats`, `POST /api/opponents/{id}/scores` | Ошибка валидации у поля, повторная отправка без потери введённого счёта |
| Отмена последнего счёта | Экран матча | `DELETE /api/opponents/{id}/scores/{gameId}` | Уведомление, если счёт уже отменён |
| Общая, дневная статистика и игры | Вкладка `Статистика` и экран матча | `GET /stats`, `/daily`, `/games` | Пустое состояние и пагинация без неактивных переходов |
| Редактирование итогов | Лист «Настройки матча» | `PUT /totals/games`, `PUT /totals/points` | Ошибка валидации под формой |
| Сброс и удаление соперника | Лист «Настройки матча` → подтверждение | `POST /reset`, `DELETE /api/opponents/{id}` | Явное подтверждение, отмена возвращает в лист |
| Создать приглашение | Лист из вкладки `Матчи` | `POST /api/invites` | Показ кода и ссылки, нативное копирование/шэринг там, где доступно |
| Ввести код приглашения | Лист из вкладки `Матчи` | `POST /api/invites/accept` | Сообщение для неверного, собственного или уже принятого кода |
| Ссылка `start=invite_<code>` | Стартовый лист Mini App | `startParam` → `POST /api/invites/accept` после подтверждения | В браузере параметр URL поддерживается как preview; бот сохраняет автоматический сценарий |
| Профиль, рейтинг, уровни | Вкладка `Профиль` | `GET /api/profile`, `POST /api/rating`, `DELETE /api/rating` | Ошибка у формы, текущий рейтинг не стирается |
| Уведомление пригласившему | Только чат | `notify_inviter_about_new_opponent` | Не переносится: это исходящее сообщение Telegram, а не экран |

## Границы переноса

Чат-специфичны команды, callback-клавиатуры, редактирование сообщений и
уведомление пригласившему. Они сохраняются в боте. Состояния ввода в чате
заменяются локальным состоянием экранов и листов Mini App. Идентичность Mini
App подтверждается сервером по Telegram `initData`; клиентский идентификатор
пользователя не считается доверенным.

## Навигация

Основные вкладки: `Матчи`, `Статистика`, `Профиль`. Выбор соперника, ввод
счёта, приглашение и опасные настройки открываются как вложенные экраны или
листы. Выбранная вкладка и позиция прокрутки сохраняются в рамках сессии.
